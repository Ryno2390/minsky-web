Godley table —
Row 0 names the stocks; row 1 is initial conditions; later rows are flows, whose cells name flow variables you drive from the canvas — a bare number balances but moves nothing. Each row must sum to 0: assets − liabilities − equity, so a transfer between an asset and a liability takes the same sign on both sides, while two liabilities take opposite signs. An unbalanced initial-conditions row usually means a missing equity column.
